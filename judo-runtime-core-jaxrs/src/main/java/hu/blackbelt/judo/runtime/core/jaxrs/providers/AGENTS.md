# AGENTS.md — `judo-runtime-core-jaxrs/src/main/java/hu/blackbelt/judo/runtime/core/jaxrs/providers`

JAX-RS `@Provider` singletons for the Judo service layer: exception mappers turning `ClientException`/`RuntimeException` into JSON error responses, a `ParamConverterProvider` binding `Date` request params to ISO-8601 strings, a `MessageBodyWriter` serializing `Payload` entities with Jackson, and a pre-matching filter that injects a default `Content-Type` on requests that carry a body.

| File | Purpose |
| --- | --- |
| `ClientExceptionMapper.java` | JAX-RS `ExceptionMapper<ClientException>` producing JSON error responses. `toResponse(ClientException)` uses `exception.getStatusCode()` with fallback `400`; entity is `exception.getDetails()` typed `application/json`. Setter `logException` (default `false`) gates an error log before mapping. |
| `ISO8601DateParamHandler.java` | JAX-RS `ParamConverterProvider` binding `Date` path/query params to `yyyy-MM-dd`. `getConverter(Class, Type, Annotation[])` returns a converter only for `Date.class`, `null` otherwise. `DateParameterConverter.fromString` throws `IllegalArgumentException` on parse failure; formats via mutable `SimpleDateFormat` field `dateFormat` (default `DEFAULT_DATE_FORMAT`) — not thread-safe. |
| `PayloadMessageBodyWriter.java` | JAX-RS `MessageBodyWriter<PayloadImpl>` serializing payloads with Jackson `ObjectMapper` (builder default `new ObjectMapper()`). `isWriteable` true only for `Payload`/`PayloadImpl`. `writeTo` swallows every `Throwable`, leaving the entity stream empty on serialization failure — callers receive no error signal. |
| `RuntimeExceptionMapper.java` | JAX-RS `ExceptionMapper<RuntimeException>` mapping failures to JSON: `ClientErrorException` passthrough, `WebApplicationException` → `400` `INVALID_JSON`, `BusinessException` → `422` `X-Fault`, else `500`; builder flags `returnRuntimeExceptions`/`includeBusinessCause`. → see `RuntimeExceptionMapper.java.AGENTS.md` |
| `SetDefaultContentTypePreMatchContainerRequestFilter.java` | `@PreMatching` `ContainerRequestFilter` injecting a default `Content-Type`. `filter(ContainerRequestContext)` returns early for GET/DELETE; otherwise sets `defaultRequestContentType` (default `application/json`, constant `APPLICTION_JSON` — sic) when the header is missing or blank. Builder param `defaultRequestContentType` overrides. |
