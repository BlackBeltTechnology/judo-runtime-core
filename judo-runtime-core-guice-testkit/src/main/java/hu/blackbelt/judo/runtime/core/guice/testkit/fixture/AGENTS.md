# AGENTS.md — `judo-runtime-core-guice-testkit/src/main/java/hu/blackbelt/judo/runtime/core/guice/testkit/fixture`

JUnit 5 fixture layer of the testkit: the `@JudoTest` annotation, the extensions that
stand up a datasource plus a Guice runtime around a test, and the value keys that decide
when a standing runtime may be reused instead of rebuilt.

| File | Purpose |
| --- | --- |
| `ByClassCacheKey.java` | Value-equal cache key for `BY_CLASS` / `SINGLETON` runtime reuse. Package-private `final class`; exports `forByClass(JudoTest, String, Class)`, `forSingleton(JudoTest, String)`, `equals`/`hashCode`. Keys on modelName, dialect, modelSource, testClass, modules, interceptors. `forSingleton` leaves `testClass` null so two classes share a runtime; `forByClass` rejects null `testClass`. |
| `CachedRuntime.java` | Bundle of one built runtime (`modelLoader` … `interceptorProvider`) reused across test methods; `ExtensionContext.Store.CloseableResource` with `AtomicBoolean`-guarded `close()`; cached fixtures skip `init(...)`. → see `CachedRuntime.java.AGENTS.md` |
| `CountingLiquibaseExecutor.java` | Delegating `SimpleLiquibaseExecutor` subclass counting successful schema creations. Exports `createDatabase(DataSource, LiquibaseModel)` and `executionCount()`. Increment happens only after `super` returns, so a failed-then-retried attempt counts once; tests assert Liquibase runs at most once per cached runtime. |
| `JudoDatasourceByClassExtension.java` | JUnit extension owning one `JudoDatasourceFixture` per test class. `beforeAll` calls `setupDatabase()` then `prepareDatasources()`, `afterAll` calls `teardownDatasource()`, `afterEach` commits any `PROPAGATION_MANDATORY` transaction and swallows `IllegalTransactionStateException`. Resolves parameters assignable from `JudoDatasourceFixture`. |
| `JudoDatasourceFixture.java` | Owns the physical test database and its Spring `DataSourceTransactionManager`. Exports `setupDatabase`, `prepareDatasources`, `teardownDatasource`, `truncateTables`/`dropTables(RdbmsModel)`, `runInTransaction(Supplier)`, `assertThrowsInTransaction`. Dialect/container/timezone read system properties `dialect`, `container`, `tz`; `setupDatabase()` must precede `prepareDatasources()`. |
| `JudoDatasourceSingletonExtension.java` | JUnit extension sharing one `static` `JudoDatasourceFixture` for the whole JVM. A `static boolean initialized` guard makes `beforeAll` idempotent across test classes; `afterAll` deliberately does NOT tear the datasource down, so the container outlives every class. `afterEach` commits a mandatory transaction if one is open. |
| `JudoRuntimeByClassExtension.java` | JUnit extension creating one `JudoRuntimeFixture` in `beforeAll` and handing the same instance to every parameter assignable from it. `beforeEach`/`afterEach` only log `Class#method`; the fixture is never re-prepared per method, so tests must not mutate it. |
| `JudoRuntimeExtension.java` | Manually constructed extension binding a model name plus a Guice `Module` (optionally a context `Map`) to a test class. `beforeAll` prepares the datasource then `prepare(modelName, dataSource, dialect)`, wrapping checked failures in `RuntimeException`; `beforeEach` runs `init(module, testInstance)` and opens a transaction. The module must come from the constructor — it reads no annotation. |
| `JudoRuntimeFixture.java` | Builds the Guice injector over a loaded JUDO model and drives test transactions. → see `JudoRuntimeFixture.java.AGENTS.md` |
| `JudoTest.java` | Meta-annotation combining `@Test` with `@ExtendWith(JudoTestExtension.class)`; declares the model, dialect, container, transaction, caching and model-source attributes. → see `JudoTest.java.AGENTS.md` |
| `JudoTestExtension.java` | Engine behind `@JudoTest`: resolves dialect/container, loads or reuses model + datasource + runtime, opens and settles the per-test transaction. → see `JudoTestExtension.java.AGENTS.md` |
| `JudoTestExtensionRouting.java` | Pure routing predicates extracted so cache decisions stay unit-testable without a model or injector. Exports `isClassScopedMode(JudoTest.DataSourceMode)` (true for `BY_CLASS`, `SINGLETON`) and `useCache(boolean, DataSourceMode, boolean)`. `BY_METHOD` and method-level annotations always take the cold path; class-scoped modes cache only when `shareInjector` is true. |
| `SingletonDatasourceKey.java` | Value-equal key for the JVM-wide singleton datasource map in `JudoTestExtension`. Package-private `final class` over `(dialect, container)` only, with `equals`/`hashCode`/`toString`. Deliberately narrower than `ByClassCacheKey`: test class, model, modules and interceptors do not change which physical database backs the fixture. |
| `SingletonModelKey.java` | Value-equal key for the JVM-wide `JudoModelLoader` map in `JudoTestExtension`. Package-private `final class` over `(modelName, dialect, modelSource)` with `equals`/`hashCode`/`toString`. Narrower than `ByClassCacheKey` because Guice modules and interceptors do not affect what is read from disk or classpath. |
| `YugabytedbSQLContainer.java` | Testcontainers `JdbcDatabaseContainer` for YugabyteDB YSQL. Constants `IMAGE=yugabytedb/yugabyte`, `DEFAULT_TAG=2.1.8.2-b1`, `YUGABYTE_PORT=5433`; exports `withDatabaseName`/`withUsername`/`withPassword`, `getJdbcUrl`, `getDriverClassName`, `getTestQueryString`. Configures via `YSQL_*` env vars, not `POSTGRES_*`, and waits on log regex `.*yugabyted started successfully.*` with a 60s timeout. |
| `logback.xml` | Test logging config on the testkit classpath. Declares a single `CONSOLE` `ConsoleAppender` with pattern `%d{HH:mm:ss.SSS} [%t] %-5level %logger{36} - %msg%n` and binds root at level `error`, so testkit runs stay quiet unless a logger is raised explicitly. |
