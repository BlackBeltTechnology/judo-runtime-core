| `JudoDefaultModule.java` | `JudoDefaultModule extends AbstractModule` wiring the whole JUDO runtime DI graph. Exports `@Builder` constructor plus inner `JudoDefaultModuleBuilder` carrying a default field for every option, `getConfiguration()`, and static `generateNewSecret()` (128 random bytes from `SecureRandom.getInstanceStrong()`, Base64-encoded as `IdentifierSignerSecret` default). `configure()` first `requestInjection(configuration.getInjectModulesTo())` then chains: `configureModels()` binds `AsmModel`, `RdbmsModel`, `MeasureModel`, `ExpressionModel`, `LiquibaseModel` and optionally `KeycloakModel`/`JudoModelLoader` (when `bindModelHolder`); `configureOptions()` binds every option value under its `JudoConfigurationQualifiers` annotation; then one configurer per service, each binding the configured instance when non-null and falling back to a provider — `RdbmsResolverProvider`, `DefaultVariableResolverProvider`, `RdbmsBuilderProvider`, `QueryFactoryProvider`, `SelectStatementExecutorProvider`, `ModifyStatementExecutorProvider`, `ExtendableCoercererProvider`/`CoercererProvider`, `DataTypeManagerProvider`, `UUIDIdentifierProviderProvider`, `DefaultIdentifierSignerProvider`, `DefaultAccessManagerProvider` (eager), `DefaultAuthenticationInterceptorProviderProvider`, `ThreadContextProvider`, `DefaultMetricsCollectorProvider`, `TransformationTraceServiceProvider`, `RdbmsInstanceCollectorProvider`, `RdbmsDAOProvider`, `DefaultActorResolverProvider`, `DispatcherFunctionProviderProvider`, `OperationCallInterceptorProviderProvider`, `DefaultDispatcherProvider` (eager), `ValidatorProviderProvider`, `DefaultPayloadValidatorProvider`, `UnsupportedExportImpl` for `Export`, `PlatformTransactionManagerProvider`. Contract: configured instance beats provider binding for each service; `Export` defaults to `UnsupportedExportImpl` when none configured. |
