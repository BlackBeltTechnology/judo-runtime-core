# `DefaultDispatcher.java` — promoted sidecar detail

| `DefaultDispatcher.java` | Central `Dispatcher` implementation wiring behaviour/script/SDK operations. Exports `callOperation(String, Map exchange)`, `load(String)` → `Optional<EOperation>`, `coerce(S, String|Class)`, `registerDataTypes()`/`unregisterDataTypes()`, filestore token endpoints (`createUploadToken`, `createDownloadToken`, `parseUploadToken`, `parseDownloadToken`). Defines exchange-key constants (`UPDATEABLE_KEY`, `DELETEABLE_KEY`, `IMMUTABLE_KEY`, `SELECTED_ITEM_KEY`, `REFERENCE_ID_KEY`, `VERSION_KEY`, `RECORD_COUNT_KEY`, `COUNT_QUERY_RECORD_KEY`, `LOCALE_KEY`, `REQUEST_PARAMETERS_KEY`, `MARK_SELECTED_RANGE_ITEMS_KEY`, `MASK`), operation-kind strings (`SDK`/`SCRIPT`/`BEHAVIOUR`), `FAULT` payload keys, `ASM_EXTENSION_ANNOTATION_INPUT_RANGE`. Builder-injected `DispatcherFunctionProvider`, `OperationCallInterceptorProvider`, `ActorResolver`, `AccessManager`, `MetricsCollector`, `Export`, transaction manager. Contract: operation fqName must resolve from the ASM model; request/response conversion reuses `RequestConverter`/`ResponseConverter`; `TransactionalOperationCall` commits only for stateful ops. |
