# AGENTS.md — `judo-runtime-core-dispatcher/src/main/java/hu/blackbelt/judo/runtime/core/dispatcher/behaviours`

Per-`AsmUtils.OperationBehaviour` dispatch handlers plus their shared plumbing. Each `*Call`
matches one operation behaviour via `isSuitableForOperation`, runs wrapped in the
`OperationCallInterceptor` chain (`CallInterceptorUtil`), and delegates to the `DAO`.
Range/validation handlers extend `AlwaysRollbackTransactionalBehaviourCall` so nothing escapes
the transaction.

| File | Purpose |
| --- | --- |
| `AddReferenceCall.java` | Runs `ADD_REFERENCE` operations: collects ids from the first parameter's reference payloads, calls `DAO.addReferences(EReference owner, instanceId, referencedIds)`. Exports `AddReferenceCallPayload` (`owner`, `instance`, `references`). Contract: bound operation required — `checkArgument(bound, "Operation must be bound")`; owner EReference and input parameter name must resolve. |
| `AlwaysRollbackTransactionalBehaviourCall.java` | Abstract base for read-only behaviours. `call()` opens a transaction, stamps `Context` with `ROLLBACK_KEY=TRUE` when it owns a new transaction, and always rolls back in `finally`; subclasses implement `callInRollbackTransaction(exchange, operation)`. Exports constant `ROLLBACK_KEY`. |
| `BehaviourCall.java` | Dispatch contract every behaviour handler implements: `isSuitableForOperation(EOperation)` gates which handler claims an operation, `call(Map<String, Object> exchange, EOperation operation)` executes it and throws `InterceptorCallBusinessException`. |
| `CollectedIdRemover.java` | Strips temporary-created identifiers from a result tree. `removeIdentifiers(Payload, Collection<Serializable> ids)` drops `__$created`, the key payload id, `DefaultDispatcher.UPDATEABLE_KEY` and `DELETEABLE_KEY` when the id is in `ids`, recursing into nested `Payload`/`Map`/`Collection` values. |
| `CreateInstanceCall.java` | Runs `CREATE_INSTANCE` operations inside a transaction. Bound vs unbound decides `DAO.create(type, input, queryCustomizer)` or `DAO.createNavigationInstanceAt(ownerId, reference, input, queryCustomizer)`; access-annotated or unmapped transfer-object owners force unbound. Exports `CreateInstanceCallPayload`. |
| `DeleteInstanceCall.java` | Runs `DELETE_INSTANCE` operations: takes the instance id from the payload and calls `DAO.delete(EClass owner, Serializable id)`. Exports `DeleteInstanceCallPayload`. Contract: operation must be bound. |
| `ExportCall.java` | Runs `EXPORT` operations in an always-rollback transaction. Resolves the reference like `ListCall`, feeds results to `Export.exportToInputStream(...)` and returns a map with `locale`, `stream`, `name` (random UUID) and `extension` `xlsx`. Exports `ExportCallPayload`. |
| `GetInputRangeCall.java` | Runs `GET_INPUT_RANGE` operations: resolves the `inputRange` extension annotation on the owning `EOperation` to an `EReference`, calls `DAO.getRangeOf(...)`/`countRangeOf(...)`, then drops temp identifiers via `MarkedIdRemover` + `CollectedIdRemover`. Contract: operation must be unbound; reads `queryCustomizer` of the first parameter and `DefaultDispatcher.RECORD_COUNT_KEY`. |
| `GetMetadataCall.java` | Runs `GET_METADATA` operations. For actor-type owners with a `realm` annotation builds a security payload from `OpenIdConfigurationProvider` (`issuer`, `authEndpoint`, `tokenEndpoint`, `logoutEndpoint`, `defaultScopes` `email`) and returns it under the `security` key. Exports `GetMetadataCallPayload`. |
| `GetPrincipalCall.java` | Runs `GET_PRINCIPAL` operations. Resolves the actor from exchange `ACTOR_KEY` or by `ActorResolver.authenticateByPrincipal(JudoPrincipal)`, loads it with `DAO.getByIdentifier(...)`, and copies transient attributes from the actor's claims. Exports `GetPrincipalCallPayload`. |
| `GetReferenceRangeCall.java` | Runs `GET_REFERENCE_RANGE` operations: `DAO.getRangeOf(...)`/`countRangeOf(...)` over the owning `EReference` with the first parameter's `queryCustomizer`, stripping temp identifiers via `MarkedIdRemover` + `CollectedIdRemover`. Contract: operation must be unbound. Exports `GetReferenceRangeCallPayload`. |
| `GetTemplateCall.java` | Runs `GET_TEMPLATE` operations: calls `DAO.getDefaultsOf(EClass owner, false)` for the operation's owning type. Exports `GetTemplateCallPayload` (`owner`, `instance`). |
| `GetUploadTokenCall.java` | Runs `GET_UPLOAD_TOKEN` operations: mints an upload `Token` via `TokenIssuer.createUploadToken(...)` with `mimeTypes`/`maxFileSize` constraints from the owning `EAttribute` type and the attribute FQN as claim context, returned as payload key `token`. Exports `GetUploadTokenCallPayload` and constant `ATTRIBUTE_KEY`. |
| `InterceptorCallBusinessException.java` | `BusinessException` subtype the interceptor chain throws to surface a business error from an `OperationCallInterceptor`; constructor takes `type`, `errorCode`, `details`, `throwable`, `locale`. |
| `ListCall.java` | Runs `LIST` operations. Chooses among `DAO.search`/`searchReferencedInstancesOf`/`searchNavigationResultAt` (actor-derived, access/unmapped, bound cases), resolves many/required results via `extractResult` (empty required list throws "No record found"), and writes count to `DefaultDispatcher.RECORD_COUNT_KEY` when `COUNT_QUERY_RECORD_KEY` set. Exports `ListCallPayload` with `recordCount`. |
| `MarkedIdRemover.java` | Recursively walks payload trees removing the marker `__$created` and, with it, the key payload id plus `DefaultDispatcher.UPDATEABLE_KEY`/`DELETEABLE_KEY`; optionally collects removed ids. Exports `process(Payload)`, `unmark(Payload)`, `processAndCollect(Payload, Collection)`. |
| `QueryCustomizerParameterProcessor.java` | Builds `DAO.QueryCustomizer` from query-customizer-shaped maps; static `convertFilterToJql(..., caseInsensitiveLike)` emits `this.<attr>` JQL. → see `QueryCustomizerParameterProcessor.java.AGENTS.md` |
| `RefreshCall.java` | Runs `REFRESH` operations: builds a `DAO.QueryCustomizer` from the first parameter and calls `DAO.searchByIdentifier(owner, id, queryCustomizer)`. Exports `RefreshCallPayload`. Contract: operation must be bound. |
| `RemoveReferenceCall.java` | Runs `REMOVE_REFERENCE` operations: collects referenced ids from the first parameter's payloads and calls `DAO.removeReferences(EReference owner, instanceId, referencedIds)`. Exports `RemoveReferenceCallPayload`. Contract: bound operation required. |
| `ServiceContext.java` | Lombok `@Builder @Getter` bag of shared dispatcher dependencies handed to every behaviour: `transactionManager`, `interceptorProvider`, `dao`, `identifierProvider`, `asmModel`, `asmUtils`, `coercer`, `actorResolver`, `context`, and `caseInsensitiveLike`. |
| `SetReferenceCall.java` | Runs `SET_REFERENCE` operations: for a many-valued owner collects the parameter's reference payloads, otherwise wraps the single payload, then calls `DAO.setReference(EReference owner, instanceId, referencedIds)`. Exports `SetReferenceCallPayload`. Contract: bound operation required. |
| `TransactionalBehaviourCall.java` | Abstract base for mutating behaviours. `call()` opens a Spring transaction and commits on success, rolls back on exception and unwraps with "Unable to rollback transaction"/"Unable to commit transaction" — only when `isNewTransaction()`; subclasses implement `callInTransaction(exchange, operation)`. |
| `UnsetReferenceCall.java` | Runs `UNSET_REFERENCE` operations: calls `DAO.unsetReference(EReference owner, Serializable instanceId)`. Exports `UnsetReferenceCallPayload`. Contract: bound operation required. |
| `UpdateInstanceCall.java` | Runs `UPDATE_INSTANCE` operations: coerces the payload identifier to the subject id and calls `DAO.update(EClass owner, input, queryCustomizer)`. Exports `UpdateInstanceCallPayload`. Contract: bound operation required and payload identifier must match the operation subject or `IllegalArgumentException("Identifier in payload must match operation subject")`. |
| `ValidateCreateCall.java` | Runs `VALIDATE_CREATE` operations in an always-rollback transaction: mirrors `CreateInstanceCall`'s bound/unbound `DAO.create`/`createNavigationInstanceAt` paths, then `MarkedIdRemover.process(result)` strips temp identifiers before return. Exports `ValidateCreateCallPayload`. |
| `ValidateOperationInputCall.java` | Runs `VALIDATE_OPERATION_INPUT` operations: seeds defaults by calling `DAO.applyDefaultsOf(EOperation.getEContainingClass(), result)` into an empty payload. Exports `ValidateOperationCallPayload` (`owner`, `input`). |
| `ValidateUpdateCall.java` | Runs `VALIDATE_UPDATE` operations in an always-rollback transaction: same identifier-match contract as `UpdateInstanceCall` plus `DAO.update(...)`, then `MarkedIdRemover.process(result)`. Exports `ValidateUpdateCallPayload`. |
