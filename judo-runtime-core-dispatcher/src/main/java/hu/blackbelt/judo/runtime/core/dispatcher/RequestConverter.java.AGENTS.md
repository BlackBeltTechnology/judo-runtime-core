# `RequestConverter.java` — promoted sidecar detail

| `RequestConverter.java` | Converts inbound request payloads against an `EClass transferObjectType` (builder). Exports `convert(Map, Map validationContext)`: validates signed identifiers via `identifierSigner`, applies DAO defaults (`dao.applyDefaultsOf`), coerces attributes via `Coercer` (enums to literal, byte arrays via filestore download token against `DownloadClaim.CONTEXT`), trims strings when `trimString`, drops non-creatable embedded references, strips unknown keys except `keepProperties`, runs `payloadValidator`. Reads validation switches `NO_TRAVERSE_KEY`, `VALIDATE_FOR_CREATE_OR_UPDATE_KEY`, `IGNORE_INVALID_VALUES_KEY` from the validation context. Contract: with `throwValidationException` failures raise `ValidationException`; invalid enum literal or file token records a per-attribute error. |
