# `DefaultIdentifierSigner.java` — promoted sidecar detail

| `DefaultIdentifierSigner.java` | JWT-signs and verifies entity identifiers (jose4j). Exports `signIdentifiers(ETypedElement, Map, boolean immutable)` writing `SIGNED_IDENTIFIER_KEY` plus `UPDATEABLE_KEY`/`DELETEABLE_KEY` from the `permissions` annotation and recursing containments; `extractSignedIdentifier(EClass, Map)` verifies the JWS, coerces the id via `identifierProvider`, checks signing type via `hasCorrectSigner` across `override` annotations and supertypes. HMAC/RSA/EC-P521 keys loaded from `secret`/`keys` or generated (`SecureRandom`); builder default algorithm `AlgorithmIdentifiers.HMAC_SHA512`. Contract: payload identifier without signature rejected; signer type mismatch throws `AccessDeniedException` ACCESS_DENIED_INVALID_TYPE. |
