# AGENTS.md — `judo-runtime-core-query/src/main/java/hu/blackbelt/judo/runtime/core/query`

Runtime entry point of the logical query model (`Select`, `SubSelect`, `Join`, `Filter`, `Feature` meta objects) that the rdbms DAO layer translates to SQL. The builder itself (`Asm2Query`, `FeatureFactory`, `JoinFactory`, `Context`, `Constants`, the feature converters, `EntityTypeExpressions`) lives in `judo-tatami-base/judo-tatami-asm2query` (package `hu.blackbelt.judo.tatami.asm2query`). This package holds `QueryFactory` (build or restore), `QueryModelLoadOrBuild` (the one restore-or-build decision) and the runtime-only `CustomJoinDefinition`. See change: persisted-query-model

| File | Purpose |
| --- | --- |
| `CustomJoinDefinition.java` | Immutable `@Builder @Getter` value object describing a custom join: `sourceIdParameterName`, `sourceIdSetParameterName`, `navigationSql`. `navigationSql` is raw SQL injected verbatim into generated queries — callers supply trusted SQL only and bind parameters through the two named parameter names. Runtime extension, keyed by live `EReference`s; copied field for field into asm2query's own 3-string `CustomJoinDefinition` on build. Consumed only while the query model is built; never persisted. |
| `QueryFactory.java` | Runtime query lookup: `getQuery(EClass)`, `getNavigation(EReference)`, `getDataQuery(EAttribute)`, `isOrdered`, `isStaticReference`, `isStaticAttribute`, `getEntityTypeExpressionsMap()` (read-only, asm2query `EntityTypeExpressions`), `getNextSourceIndex/TargetIndex`, `dataExpressionToFeature(DataExpression, asm2query Context, Target, EAttribute)`. Two paths: build (public constructors and `builder()`, delegates to `Asm2Query`; `coercer` deprecated and ignored) and restore (`restore(AsmModel, MeasureModel, QueryModel)` / `restore(ResourceSet, ResourceSet, QueryModel)`, wraps a `QueryIndex`). → see `QueryFactory.java.AGENTS.md` |
| `QueryModelLoadOrBuild.java` | The only place that decides between restoring a persisted query model and building one (D5 table); modes `auto` / `load` / `build` (`Mode.parse`); implements `Supplier<QueryFactory>`; builder `queryModelLoadOrBuild()`. → see `QueryModelLoadOrBuild.java.AGENTS.md` |
