# AGENTS.md — `judo-runtime-core-dao-rdbms/src/main/java/hu/blackbelt/judo/runtime/core/dao/rdbms/query/processor`

Join processors: each converts a `hu.blackbelt.judo.meta.query` join node (simple, container,
cast, custom, filter, subselect) into RDBMS join rows, parameter-bundle DTOs included.

| File | Purpose |
| --- | --- |
| `AncestorJoinsProcessor.java` | Emits `RdbmsTableJoin` per ancestor `EClass` of a query node into the caller's join collection. Exports `AncestorJoinsProcessor.builder()` over `@NonNull` `RdbmsResolver`/`AncestorNameFactory`/`DescendantNameFactory` and `process(Collection<RdbmsJoin>, Node, RdbmsBuilderContext)`. Ancestor list resolved from `builderContext.getAncestors()`, falling back to the enclosing `SubSelect`/`Node`. |
| `CastJoinProcessor.java` | Expands a cast `Node` into `RdbmsTableJoin` rows, one per castable type. Exports `CastJoinProcessor.builder()` over `@NonNull RdbmsResolver` and `process(Node, RdbmsBuilderContext) : List<RdbmsJoin>`. Type set = cast target type + `getEAllSuperTypes()`, sorted so subtypes precede supertypes via the `eAllSuperTypes`-containment comparator. |
| `ContainerJoinProcessor.java` | Folds a `ContainerJoin`'s references into join rows through the builder's simple-join path. Exports `ContainerJoinProcessor.builder()` over `@NonNull RdbmsResolver` and `process(ContainerJoin, RdbmsBuilderContext) : List<RdbmsJoin>`. Source type from partner node or first reference; per-reference `rdbmsBuilder.processSimpleJoin(SimpleJoinProcessorParameters...)` calls, accumulated in order. |
| `CustomJoinProcessor.java` | Builds `RdbmsCustomJoin` from hand-written navigation SQL. Exports `CustomJoinProcessor.builder()` over `@NonNull RdbmsResolver`/`AsmModel` and `process(CustomJoin, RdbmsBuilderContext) : List<RdbmsJoin>`. Backtick-delimited identifiers in `getNavigationSql()` resolved against the asm model via `resolveRdbmsNames` (character-iterator scan); backtick-free SQL passes through verbatim. |
| `FilterJoinProcessor.java` | Translates a `SubSelect`'s `Filter` into join rows and condition `RdbmsField`s. Exports `FilterJoinProcessor.builder()` and `process(FilterJoinProcessorParameters, RdbmsBuilderContext)`. Reads joins/conditions/query/partner table out of the parameter bundle, reuses `RdbmsAliasUtil.getParentIdColumnAlias` for parent-id columns, and tracks already-processed join nodes to avoid duplicate joins. |
| `FilterJoinProcessorParameters.java` | Lombok `@Builder/@Getter/@ToString` parameter bundle for `FilterJoinProcessor`. Carries `@NonNull` `joins`, `query` (`SubSelect`), `processedNodesForJoins`, `conditions` (`List<RdbmsField>`), `filter`, `partnerTable` (`Node`); `partnerTablePrefix` defaults to `""`, `addJoinsOfFilterFeature` to false. |
| `JoinProcessParameters.java` | Lombok `@Builder/@Getter/@ToString` parameter bundle for generic join processing. Carries `@NonNull` `builderContext` and `join` (`Node`), plus optional `withoutFeatures` toggle and `mask` (`Map<String,Object>`). |
| `SimpleJoinProcessor.java` | Builds reference joins between two types, with optional postfix. Exports `SimpleJoinProcessor.builder()` over `@NonNull RdbmsResolver`/`Rules`/`AncestorNameFactory`/`DescendantNameFactory` and `process(SimpleJoinProcessorParameters) : List<RdbmsJoin>`. Consults `meta.rdbmsRules.Rule`/`Rules`; resolves `reference`/`opposite` `EReference` pair. |
| `SimpleJoinProcessorParameters.java` | Lombok `@Builder/@Getter/@ToString` parameter bundle for `SimpleJoinProcessor`. Carries `@NonNull` `join` and `builderContext`; stores the optional `reference`/`opposite` `EReference` pair; `postfix` defaults to `""`. |
| `SubSelectJoinProcessor.java` | Turns a `SubSelectJoin` into an `RdbmsQueryJoin` over its nested subselect. Exports `SubSelectJoinProcessor.builder()` over `@NonNull RdbmsResolver` and `process(SubSelectJoin, boolean withoutFeatures, Map<String,Object> mask, RdbmsBuilderContext) : List<RdbmsJoin>`. Mask keyed under `subSelect.getTransferRelation().getName()`; `process` mutates the subselect, appending `join.getFilters()` to it. |
