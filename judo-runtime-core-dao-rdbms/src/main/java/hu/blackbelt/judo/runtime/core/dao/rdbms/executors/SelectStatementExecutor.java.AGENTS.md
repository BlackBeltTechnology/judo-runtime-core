# `SelectStatementExecutor.java`

SQL read path: `executeSelect` overloads (transfer type + `DAO.QueryCustomizer`, `EReference` navigation from parents, `EAttribute` static data), `countSelect` overloads, `selectMetadata` returning `Optional<Payload>`; all route through private `runQuery`/`countQuery` and recurse via `runSubQuery`/`executeSubQuery`.
`runQuery` builds `RdbmsResultSet`, chunks `instanceIds`/`parentIds` by `chunkSize` (`Lists.partition`), merges rows into per-`Target` `LinkedHashMap`; child records nested under `RdbmsAliasUtil.getParentIdColumnAlias(query.getContainer())` key; repeated `SubSelect` recursion bounded by `maximumRecursionCount` via `subSelectStack`.
Contracts: `queryFactory.getQuery` must know the type else `IllegalArgumentException`; `Select` cloned when filter/orderBy/seek present so cached query pristine; `executeSelect(EReference)` requires prebuilt subselect (`"Subselect must be prepared by query factory"`); `executeSelect(EAttribute)` asserts exactly one row (`"Invalid result set"`); subselect needs `transferRelation`, parent-key record must resolve (`"Unknown parent ID"`).
Constructor registers every expression translator (`MeasuredDecimalConstantTranslator`, comparisons, `KleeneTranslator`, `StringComparisonTranslator`, ...) into `Translator` under `METRICS_SELECT_*`/`METRICS_COUNT_*` scoped metrics with `rdbmsBuilder.getConstantFields()` set/remove; `getFieldValue` coerces to declared types (custom type registration, `EEnum` → `Integer`, byte arrays → `FileType`, Timestamp/Time offset fixup).
