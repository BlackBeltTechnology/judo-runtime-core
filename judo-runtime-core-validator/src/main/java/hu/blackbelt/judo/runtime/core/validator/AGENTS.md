# AGENTS.md — `judo-runtime-core-validator/src/main/java/hu/blackbelt/judo/runtime/core/validator`

Constraint validators for payload features, the traversing top-level `DefaultPayloadValidator`, and the `ValidatorProvider` registry wiring them.

| File | Purpose |
| --- | --- |
| `DefaultPayloadValidator.java` | Implements `PayloadValidator`. `validatePayload(EClass, Payload, Map, boolean)` traverses via `PayloadTraverser` and runs registered `Validator`s per attribute/reference; throws `ValidationException` when the flag is set. Exports `validateReference`, `validateAttribute`, enum `RequiredStringValidatorOption`, statics `ATTRIBUTE_TO_MODEL_TYPE`/`REFERENCE_TO_MODEL_TYPE`. Reference values must be `Payload` instances or `IllegalStateException`. → see `DefaultPayloadValidator.java.AGENTS.md` |
| `DefaultValidatorProvider.java` | Implements `ValidatorProvider`. `@Builder` ctor seeds `MaxLengthValidator`, `MinLengthValidator`, `PrecisionValidator`, `PatternValidator`, plus `RangeValidator`/`UniqueAttributeValidator` when `DAO`, `IdentifierProvider`, `Context`, `AsmModel` supplied. Exports `addValidator`, `removeValidator`, `replaceValidator`, `getInstance(Class)`, `getValidators`; null deps skip range/uniqueness checks. |
| `DummyValidator.java` | Implements `Validator`. `isApplicable` always returns `false`; `validateValue` always returns an empty collection. No-op placeholder; registering it disables validation for any feature asked of it. |
| `MaxLengthValidator.java` | Implements `Validator`; applies to `EAttribute` whose `constraints` annotation carries `maxLength`. Flags `ERROR_MAX_LENGTH_VALIDATION_FAILED` for String values longer than the parsed limit. Exports `isApplicable`, `validateValue`; throws `IllegalStateException` when a `maxLength` constraint is unparsable. |
| `MinLengthValidator.java` | Implements `Validator`; applies to `EAttribute` whose `constraints` annotation carries `minLength`. Flags `ERROR_MIN_LENGTH_VALIDATION_FAILED` for String values shorter than the limit. Exports `isApplicable`, `validateValue`; throws `IllegalStateException` when a `minLength` constraint is unparsable. |
| `PatternValidator.java` | Implements `Validator`; applies to `EAttribute` whose `constraints` annotation carries `pattern`. Compiles via `Pattern.compile`; flags `ERROR_PATTERN_VALIDATION_FAILED` when a String value fails `matches()`. Exports `isApplicable`, `validateValue`; unparsable regex surfaces as `PatternSyntaxException`. |
| `PrecisionValidator.java` | Implements `Validator`; applies to `EAttribute` with `constraints` detail `precision` (optional `scale`). Validates `Number` values (`validateInteger` for integral, `validateDecimal` for BigDecimal, negative scale normalized); flags `ERROR_PRECISION_VALIDATION_FAILED`/`ERROR_SCALE_VALIDATION_FAILED`. Exports `isApplicable`, `validateValue`; non-Number value throws `IllegalStateException`. |
| `RangeValidator.java` | Implements `Validator`; applies to embedded `EReference` with `constraints` detail `range`. Counts current range via `dao.countRangeOf`; flags `ERROR_NOT_ACCEPTED_BY_RANGE` when the candidate id falls outside. Exports `isApplicable`, `validateValue`; `@RequiredArgsConstructor` ctor takes `DAO`, `IdentifierProvider`, `Context`, `AsmModel` — without `DAO` range checks cannot run. |
| `UniqueAttributeValidator.java` | Implements `Validator`; applies to `EAttribute` mapped to an identifier. Converts values to JQL (`convertFilterToJql`), `dao.search`es up to 2 rows; flags `ERROR_IDENTIFIER_ATTRIBUTE_UNIQUENESS_VIOLATION` when the value persists under another id (`THIS_NAME`). Exports `UNIQUE_ATTRIBUTE_VALIDATOR_CONTEXT`; wrong value type throws `IllegalArgumentException`. |
| `Validator.java` | Interface for per-feature validators. Exports `isApplicable(EStructuralFeature)`, `validateValue(Payload, EStructuralFeature, Object, Map)`, static `addValidationError(...)`; declares `ERROR_*` codes (`ERROR_MISSING_REQUIRED_ATTRIBUTE`, `ERROR_TOO_MANY_ITEMS`) plus `SIZE_PARAMETER`, `CONSTRAINTS`. Implementers may answer `isApplicable` true only for features `validateValue` can handle. |
| `ValidatorProvider.java` | Interface for the validator registry. Exports `addValidator`, `removeValidator`, `removeValidatorType(Class)`, `replaceValidator`, `getInstance(Class)`, `getValidators`; `getInstance` returns `Optional<Validator>` — empty when no validator of the requested type is registered. |
